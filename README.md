# Al-Noor Auto Workshop (portfolio project)

Static landing page: HTML5, CSS3 (Grid, Flexbox, variables), and about 80 lines of vanilla JS. No build step. Open `index.html`.

## Replace before real use
- **WhatsApp number:** `WHATSAPP_NUMBER` at the top of `js/script.js` (country code, digits only). The `wa.me` links in the HTML are a no-JS fallback.
- **Business details:** address, phone, email and hours appear in the Location section, the footer and the JSON-LD block in `<head>`.
- **Map:** change the `q=` value in the iframe `src` (or paste a Google Maps embed URL).
- **Images:** `images/*.svg` are placeholders. Add real photos (e.g. `hero.jpg`, 1600x900; gallery 600x450), update the `src` paths in `index.html`, and keep `width`/`height`.
- **SEO:** canonical URL, Open Graph and Twitter tags use `example.com`.
- **Reviews:** demo only. Replace with real, permissioned reviews before launch.
- **Form:** front-end validation only. Connect to a backend or a form service to receive inquiries.
